🤖 Создание робота/активити

Эта инструкция показывает, как создать новое робота/активити в приложении RoboREST для Битрикс24, настроить входящие и исходящие параметры, работать с редактором Python-кода и проверить результат тестом.

1️⃣ ➕ Шаг 1: создание нового робота/активити

Новое активити удобнее создать одним из двух способов: взять за основу подходящий пример на вкладке «Примеры» либо начать с нуля — на главном экране RoboREST нажмите зелёную кнопку «+ Добавить активити / робота» в правом верхнем углу.

Откроется страница создания нового робота/активити. Введите название и перейдите к настройке параметров.

2️⃣ ⬅️ Шаг 2: настройка входящих параметров

Входящие параметры — это данные, которые робот получит на вход (например, из предыдущего шага бизнес-процесса).

В блоке «Входящие параметры» нажмите кнопку «+ Добавить поле». Заполните появившиеся строки:

  • Код поля: генерируется автоматически (например, field_input_1).
  • Название поля: введите понятное имя (например, «Идентификатор сделки»).
  • Значение для тестирования: заполните значением для тестирования.

Добавьте второе поле таким же образом (например, «Идентификатор контакта»).

3️⃣ ➡️ Шаг 3: настройка исходящих параметров

Исходящие параметры — это данные, которые робот вернёт после выполнения своей работы.

В блоке «Исходящие параметры» нажмите «+ Добавить поле». Заполните поля:

  • Код поля: например, field_output_1.
  • Название поля: например, понятное имя для field_output_1.

Важно: если параметр должен возвращать список данных (массив), включите переключатель «Множественное» справа от поля.

4️⃣ 🧑‍💻 Шаг 4: работа с редактором кода

Прокрутите страницу вниз до блока «Код робота/активити». Здесь находится редактор Python-кода с подсветкой синтаксиса и автодополнением, аналогичный редактору VS Code.

В начале файла обычно есть справка в комментариях: какие объекты и библиотеки доступны по умолчанию:

  • params — список всех входящих и исходящих параметров.
  • logger — логгер для отладки.
  • accessToken, memberId, domain — данные портала.
  • B24App — объект Python SDK для работы с REST API Битрикс24.
  • Стандартные библиотеки Python: math, datetime, os, json, http.client и другие.
  • Дополнительные библиотеки: b24pysdk, qrcode, requests, pillow, numpy, matplotlib.

5️⃣ 🧪 Шаг 5: тестирование робота/активити

Перед сохранением стоит проверить, как работает код. Прокрутите вниз до блока «Тестирование запросов».

Вернитесь к входящим параметрам и заполните колонку «Значение для тестирования» (например, 123). Затем нажмите синюю кнопку «Выполнить тест» справа от блока тестирования.

Смотрите блок «Логи» внизу. При успешном выполнении появятся зелёные метки INFO. Ошибки отображаются красным уровнем ERROR.

6️⃣ 🧾 Шаг 6: использование логгера

Для отладки выводите сообщения в лог. В редакторе кода (ниже комментариев со справкой) можно добавить, например: 

logger.info("Тестовое сообщение")
logger.debug("Отладочная информация")
logger.warning("Предупреждение")

Снова нажмите «Выполнить тест». В блоке «Логи» появятся ваши сообщения. Фильтруйте их вкладками сверху (DEBUG, INFO, WARN, ERROR), чтобы видеть только сообщения нужного уровня.

7️⃣ 💾 Шаг 7: сохранение

Когда параметры настроены, код написан и протестирован, нажмите синюю кнопку «Сохранить изменения» внизу страницы (или в правом нижнем углу).

После сохранения новая активити создана и доступна для использования в конструкторе бизнес-процессов Битрикс24.
