How to Use the RoboREST App

🚀 RoboREST is a Bitrix24 app that lets you create your own robots and activities in Python. It is a great fit when built-in automation is not enough: you can integrate external APIs, work with files and databases, build reports, run scheduled tasks, and add widgets.

  • 🔗 Integrations with external services via API.
  • ⚙️ Custom automation logic tailored to your processes.
  • 📊 Reports, charts, and data processing inside your scenarios.
  • 🧩 Widgets and additional UI elements.

👥 Who is RoboREST for?

  • 🛠️ Integrators - quickly build custom scenarios that are not available in standard Bitrix24.
  • 📁 Portal administrators - automate routine operations and reduce manual work.
  • 📈 Business analysts - connect processes between CRM, ERP, and other systems.
  • 🎯 Project managers - launch complex but manageable business processes.

⚡ 5-Minute Quick Start

  1. 🖥️ Open the RoboREST dashboard.
  2. ➕ Click the button to add a new robot/activity.
  3. 🧱 Select a template or create a solution from scratch.
  4. 🧪 Run a test and check the result.
  5. 🔗 Add the robot/activity to the required Bitrix24 business process.
  6. ⏰ If needed, set up scheduled runs (cron).

💳 Limits and Billing

  • ✅ 100 requests per month are available for free.
  • 📌 The limit includes robot/activity runs and cron jobs.
  • 🧪 Test runs from the editor are unlimited.
  • 🆓 Calls to created widgets are not charged.
  • ➕ You can purchase additional requests when needed.
