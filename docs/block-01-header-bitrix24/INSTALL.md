# Инструкция по установке блока Header

## Быстрая установка (для тестирования)

### Шаг 1: Скопируйте HTML код
1. Откройте файл `block.html`
2. Скопируйте весь код
3. В Bitrix24 Sites добавьте блок "HTML код"
4. Вставьте скопированный код

**Ограничение**: При этом способе редактирование будет ограничено, так как manifest не подключен.

## Полная установка (с редактированием)

### Шаг 1: Подготовка файлов
Убедитесь, что у вас есть все файлы:
```
block-01-header-bitrix24/
├── block.html
├── manifest.php
└── lang/
    ├── ru/
    │   └── block.php
    └── en/
        └── block.php
```

### Шаг 2: Загрузка на сервер
Загрузите все файлы на сервер Bitrix24 в папку:
```
/bitrix/blocks/landing/header_msite/
```

**Важно**: 
- Путь должен быть точным
- Права доступа: 755 для папок, 644 для файлов
- Владелец файлов должен соответствовать пользователю веб-сервера

### Шаг 3: Проверка установки
1. Откройте конструктор сайта в Bitrix24
2. Нажмите "Добавить блок"
3. Найдите блок "Header" в разделе "Menu"
4. Добавьте блок на страницу

### Шаг 4: Настройка
После добавления блока вы сможете:
- Редактировать логотип (заменить изображение)
- Изменять пункты меню (добавлять/удалять/редактировать)
- Настраивать стили через интерфейс Bitrix24
- Изменять ссылки и тексты кнопок

## Структура папок на сервере

```
/bitrix/blocks/landing/header_msite/
├── block.html          (обязательно)
├── manifest.php        (обязательно)
└── lang/
    ├── ru/
    │   └── block.php   (опционально, для русского языка)
    └── en/
        └── block.php   (опционально, для английского языка)
```

## Решение проблем

### Блок не появляется в библиотеке
1. Проверьте путь к файлам
2. Убедитесь, что manifest.php корректен
3. Очистите кеш Bitrix24 (Настройки → Производительность → Очистить кеш)

### Ошибки при редактировании
1. Проверьте права доступа к файлам
2. Убедитесь, что модуль Landing активирован
3. Проверьте логи ошибок PHP

### Меню не редактируется
1. Убедитесь, что используется правильная структура меню в manifest.php
2. Проверьте классы в block.html (должны совпадать с manifest)
