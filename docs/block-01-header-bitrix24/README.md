# Блок Header для Bitrix24 Sites

Редактируемый блок шапки сайта, соответствующий требованиям Bitrix24 Landing API.

## Структура файлов

```
block-01-header-bitrix24/
├── block.html          # HTML структура блока
├── manifest.php        # Manifest файл с описанием редактируемых узлов
├── lang/
│   ├── ru/
│   │   └── block.php  # Русские языковые файлы
│   └── en/
│       └── block.php  # Английские языковые файлы
└── README.md          # Документация
```

## Установка в Bitrix24 Sites

### Вариант 1: Через конструктор (рекомендуется)

1. Откройте конструктор сайта в Bitrix24
2. Добавьте блок "HTML код" или "Кастомный HTML"
3. Скопируйте содержимое `block.html`
4. Вставьте в блок

**Примечание**: При использовании этого варианта редактирование будет ограничено, так как manifest не будет подключен.

### Вариант 2: Как кастомный блок (полная функциональность)

1. Загрузите все файлы блока на сервер Bitrix24 в папку:
   ```
   /bitrix/blocks/landing/header_msite/
   ```

2. Структура должна быть:
   ```
   /bitrix/blocks/landing/header_msite/
   ├── block.html
   ├── manifest.php
   └── lang/
       ├── ru/
       │   └── block.php
       └── en/
           └── block.php
   ```

3. Обновите страницу конструктора - блок появится в библиотеке блоков в разделе "Menu"

## Редактируемые элементы

Блок поддерживает редактирование следующих элементов:

### Логотип
- **Изображение**: `.landing-block-node-img` - можно заменить изображение через интерфейс редактора
- **Ссылка**: `.landing-block-node-logo` - можно изменить ссылку логотипа

### Меню (многоуровневое)
Блок использует специальный ключ `menu` в manifest для поддержки многоуровневого меню:
- **Главное меню**: `.landing-block-node-menu-nav` - можно добавлять/удалять/редактировать пункты меню
- **Мобильное меню**: `.landing-block-node-menu-mobile` - отдельное меню для мобильных устройств
- **Ссылки меню**: редактируются через интерфейс меню в Bitrix24

### Переключатель языка
- **Кнопки языка (десктоп)**: `.landing-block-node-lang-btn` - можно изменить ссылки и текст
- **Кнопки языка (мобильный)**: `.landing-block-node-lang-btn-mobile` - мобильная версия

### CTA кнопка
- **Кнопка (десктоп)**: `.landing-block-node-button` - можно изменить текст и ссылку
- **Кнопка (мобильный)**: `.landing-block-node-button-mobile` - мобильная версия

## Настройки стилей

Через интерфейс Bitrix24 можно настроить:

- **Типографику** ссылок меню (цвет, размер, шрифт)
- **Стиль кнопки** (цвет, обводка, скругление)
- **Отступы контейнера** (padding)
- **Фон контейнера** (background)
- **Настройки навигации** (navbar)

## Адаптивность

Блок автоматически адаптируется под мобильные устройства:
- На экранах < 768px показывается гамбургер-меню
- Десктопное меню скрывается
- Мобильное меню открывается по клику на гамбургер

## Требования

- Bitrix24 версии 18.7.500 или выше
- Модуль Landing должен быть установлен и активирован

## Поддержка

При возникновении проблем:
1. Проверьте права доступа к файлам
2. Убедитесь, что модуль Landing активирован
3. Очистите кеш Bitrix24
