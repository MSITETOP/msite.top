Инструкция по работе с приложением RoboREST

🚀 RoboREST — приложение для Битрикс24, с которым вы создаете собственные роботы и активити на Python. Оно подходит, когда стандартной автоматизации недостаточно: можно подключать внешние API, работать с файлами и базами данных, строить отчеты, запускать задачи по расписанию и добавлять виджеты.

  • 🔗 Интеграции с внешними сервисами через API.
  • ⚙️ Кастомная логика автоматизации под ваши процессы.
  • 📊 Отчеты, графики и обработка данных внутри сценариев.
  • 🧩 Виджеты и дополнительные элементы интерфейса.

👥 Для кого подходит RoboREST?

  • 🛠️ Интеграторам — быстро собирать кастомные сценарии, которых нет в стандартном Битрикс24.
  • 📁 Администраторам портала — автоматизировать рутинные операции и уменьшать ручной труд.
  • 📈 Бизнес-аналитикам — связывать процессы между CRM, ERP и другими системами.
  • 🎯 Руководителям проектов — запускать сложные, но управляемые бизнес-процессы.

⚡ Быстрый старт за 5 минут

  1. Откройте дашборд RoboREST.
  2. Нажмите кнопку добавления нового робота/активити.
  3. Выберите шаблон или создайте решение с нуля.
  4. Запустите тест и проверьте результат.
  5. Добавьте робота/активити в нужный бизнес-процесс Битрикс24.
  6. При необходимости настройте запуск по расписанию (крон).

💳 Лимиты и тарификация

  • ✅ Бесплатно доступно 100 запросов в месяц.
  • 📌 В лимит входят запуски роботов/активити и крон-заданий.
  • 🧪 Тестовые запуски из редактора без ограничений.
  • 🆓 Обращения к созданным виджетам не тарифицируются.
  • ➕ При необходимости можно докупить нужное количество запросов.
